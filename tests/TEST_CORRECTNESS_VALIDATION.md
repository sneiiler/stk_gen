# 正确性和隔离性验证函数测试

## 概述

`test_correctness_validation.py` 是为 `_validate_correctness_and_isolation_for_single_slice` 函数创建的全面测试套件。该函数是卫星分簇验证器的核心组件，负责验证分簇结果的正确性和隔离性。

## 函数功能

`_validate_correctness_and_isolation_for_single_slice` 函数主要验证以下几个方面：

### 1. 致命错误检测（0分）
- 分簇中包含输入数据中不存在的卫星或目标
- 一旦发现此类错误，直接给0分

### 2. 目标遗漏检测（最多扣50分）
- 检查输入中的目标是否全部被分簇覆盖
- 按遗漏比例扣分：遗漏率 × 50分

### 3. 隔离性验证（最多扣50分）
#### 3.1 跨簇连接检测（最多扣25分）
- 检查卫星和目标是否在同一个簇中
- 按跨簇连接比例扣分：跨簇率 × 25分

#### 3.2 多簇归属检测（最多扣25分）
- 检查同一卫星或目标是否出现在多个簇中
- 每个多簇元素扣5分，最多扣25分

## 测试场景

### 测试1: 完美分簇
- **目的**: 验证理想情况下的满分
- **期望**: 100分
- **验证**: 无任何错误或警告

### 测试2: 目标遗漏
- **目的**: 验证目标覆盖率扣分机制
- **场景**: 25%的目标未被覆盖
- **期望**: 87分（扣12.5分）

### 测试3: 跨簇连接
- **目的**: 验证隔离性检查
- **场景**: 卫星和其观测目标在不同簇中
- **期望**: 93分（扣6.2分）

### 测试4: 多簇归属
- **目的**: 验证重复元素检查
- **场景**: 卫星和目标同时出现在多个簇中
- **期望**: 90分（各扣5分）

### 测试5: 致命错误
- **目的**: 验证不存在元素处理
- **场景**: 分簇包含输入中不存在的卫星和目标
- **期望**: 0分

### 测试6: 复杂场景
- **目的**: 验证多种问题组合处理
- **场景**: 同时包含目标遗漏、跨簇连接、多簇归属
- **期望**: 70分（综合扣分）

### 测试7: 空簇场景
- **目的**: 验证边界情况处理
- **场景**: 分簇为空，所有目标遗漏
- **期望**: 50分（遗漏率100%）

### 测试8: 大规模场景
- **目的**: 验证算法在大数据集上的表现
- **场景**: 20颗卫星，30个目标，5个分簇
- **期望**: 100分（完美分簇）

### 测试9: 单元素边界
- **目的**: 验证最小规模情况
- **场景**: 1颗卫星，1个目标，1个分簇
- **期望**: 100分

### 测试10: 严重违规
- **目的**: 验证极端违规情况
- **场景**: 大量跨簇连接和多簇归属
- **期望**: 80分（扣20分）

## 验证结果说明

- **✅ 正常**: 没有错误或警告，函数按预期工作
- **⚠️ 有警告**: 有警告但没有致命错误，扣分适中
- **❌ 发现错误**: 有致命错误或严重问题，扣分较多

## 扩展测试

可以通过修改测试数据来验证其他场景：

1. **修改扣分比例**: 调整目标遗漏数量测试不同的扣分情况
2. **增加测试规模**: 创建更大规模的卫星和目标数据
3. **特殊连接模式**: 测试特定的卫星-目标连接模式
4. **历史数据**: 添加历史分簇结果测试稳定性（需要其他验证函数）

## 注意事项

1. 测试使用模拟数据，确保覆盖所有主要功能点
2. 扣分机制已通过实际运行验证正确性
3. 可以作为函数使用的参考文档
4. 测试结果稳定，可用于回归测试
